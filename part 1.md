# 🧠 Part 1 — 100+ Ubuntu Keyboard Shortcuts for Productivity & Power

> ⚙️ These shortcuts are valid for Ubuntu 22.04 LTS and later, mostly GNOME desktop environment (default). They dramatically speed up navigation, multitasking, and terminal work.
> 

---

## 🧭 1. System Navigation & Windows Management

| Shortcut | Description |
| --- | --- |
| **Super** | Open *Activities Overview* (search, apps, windows). |
| **Super + A** | Show all installed applications. |
| **Super + S** | Display *Workspaces* overview. |
| **Super + Tab** | Cycle through open applications. |
| **Alt + Tab** | Switch between running applications. |
| **Alt + ` (backtick)** | Switch between windows of same app. |
| **Super + Up Arrow** | Maximize current window. |
| **Super + Down Arrow** | Restore / minimize current window. |
| **Super + Left/Right Arrow** | Snap window to half screen. |
| **Super + D** | Show desktop (toggle hide/show windows). |
| **Ctrl + Alt + Arrow Left/Right** | Switch between workspaces. |
| **Shift + Super + Arrow Left/Right** | Move window to another workspace. |
| **Alt + F4** | Close current window. |
| **Ctrl + Q** | Quit application. |
| **Ctrl + W** | Close current tab or document. |

## ✅ Summary

- Learn these by **category** first — Terminal, Windows, Workspaces.
- Practice daily for muscle memory.
- Customize via **Settings → Keyboard → Shortcuts** if needed.
- Power users often remap shortcuts for efficiency (e.g., using `Alt+Enter` for terminal).
